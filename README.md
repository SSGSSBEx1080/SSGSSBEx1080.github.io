# ZitraksMode Wiki

Отдельная страница под каждый пункт мода.

```
index.html                  хаб: все 29 пунктов + история разработки
shared/core.css, core.js    общая база (шрифты, топбар, 3D-куб, тосты ачивок)
shared/points.js            список пунктов: номер, название, дата, ссылка на страницу
data/*.js                   данные, собранные из файлов мода (не править руками)
assets/                     шрифты и оригинальные текстуры (+ апскейл x8)
pages/NN-*/                 страница пункта: index.html + style.css + app.js
tools/build_data.py         сборщик данных из файлов мода
mod-src/                    исходные файлы мода: advancements/, recipes/, textures/, HISTORY.md
assets/textures/mc/         ванильные текстуры Minecraft 1.19.2 (кирки, трещины, GUI)
assets/vanilla/vanilla-1.19.2.zip  ВСЕ ванильные текстуры и модели 1.19.2 из client.jar одним архивом (скрипты читают через tools/vanilla.py)
assets/brand/               логотип мода
tools/mc_icon.py            иконки блоков «как в инвентаре» из настоящих ванильных моделей
tools/get_vanilla.py        перекачать эту базу с серверов Mojang
tools/serve.py              локальный сервер без кэша (всегда свежие файлы)
tools/render_model.py       рендер любой модели из data/*.js в PNG (иконки)
```

## Обновить данные из мода
    # положить файлы в mod-src/ (структура как в resources мода), затем:
    python3 tools/build_data.py

## Посмотреть локально
    python3 tools/serve.py 8080
    # открыть http://localhost:8080
Можно и без сервера: сайт работает, если просто открыть index.html из папки.

## Ванильная база
`assets/vanilla/vanilla-1.19.2.zip` → `textures/` — все текстуры игры 1.19.2 (block, item, entity, gui, particle...),
взятые из официального client.jar. Сборщики страниц (`build_p04.py`, `build_p05.py`) берут текстуры отсюда
и только если чего-то нет, качают из интернета. Перекачать базу: `python3 tools/get_vanilla.py`. Архив, а не 5591 файл, чтобы не раздувать проект: `tools/vanilla.py` сам распакует его во временную папку системы, когда он нужен скрипту. Хочешь смотреть глазами — распакуй в `assets/vanilla/1.19.2/`, скрипты возьмут оттуда.
Звуков в client.jar нет: ванильные звуки качаются сборщиками по одному.

## Добавить новый пункт
1. Скопировать папку `pages/01-number-blocks` -> `pages/NN-название`
2. В `shared/points.js` указать `page: "pages/NN-название/index.html"`
3. Переписать стиль и логику под пункт

## №03 · Снайперки (`pages/03-snipers/`)
- `data/p03_snipers.js`: все числа из кода (урон, КД, пуля, чары, ульта, рецепты, ачивки, хронология). Правится руками.
- `data/p03_models.js`: модели снайперки и пули, генерируется `tools/build_p03.py` (текстуры, иконки, спрайты мобов, ванильные звуки). Руками не править.
- `model3d.js`: CSS-3D рендер Java-моделей Blockbench (грань = div + matrix3d).
- `range.js`: тир от первого лица (canvas), механика 1:1 с SniperItem / BulletEntity / SniperUltimateAbility. Отладка из консоли: `ZM.p03range`.
- Ачивки: 6 штук одной цепочкой из `mod-src/advancements/03_sniper/*.json` (пуля → железная → золотая → алмазная → незеритовая → «Король снайперов»), 130 XP. На сайте выдаются кликом по результату в верстаке, кнопкой «+64» и убийством со 100+ м в тире.
- Текстуры: все 4 снайперки на своих текстурах. 3D-модели рисуются WebGL (gl3d.js), без WebGL — CSS (model3d.js). Выстрел ульты: `sniper_ultimate_shot.ogg` из мода, луч бьёт сразу по R, без зарядки. Общая громкость: `MASTER_VOLUME` в app.js.
- Тир: Pointer Lock (клик захватывает мышь, Esc отпускает). Если захват запрещён, работает запасной режим «курсор = взгляд».
- localStorage: `zm:p03.adv`, `p03.tasks`, `p03.ammo`, `p03.ench`, `p03.rec`, `p03.snd`.

## №06 · Лабубу-система (`pages/06-labubu/`)
- Стиль: кейс-опенинг. Фиолетовый бархат, розовый неон, цвета редкостей из `LabubuRarity`. Шрифты Rubik Bubbles и Rubik лежат локально в `assets/fonts/`.
- **Данные:** `data/p06_labubu.js`. Здесь редкости с весами, 26 фигурок, параметры рулетки, ачивки и история. **Названия фигурок правятся тут, в поле `name`.**
  Механика по коду описана в `mod-src/java/p06/MECHANICS.md`, ачивки лежат в `mod-src/advancements/p06/`.
- **Сборка:** `python3 tools/build_p06.py --icons`.
  - Модели берутся из `mod-src/models/labubu/`, текстуры из `mod-src/textures/labubu/` (ужимаются до 192 px в WebP) и `mod-src/textures/labubu_box/`.
  - На выходе получаются `data/p06_models.js`, `data/p06_tex.js` (data: URI, работает с file://) и иконки `assets/textures/p6/icons/*.png`.
  - Грани `#missing` и отсутствующие текстуры рисуются ванильной фиолетово-чёрной шахматкой, как в игре.
- `gl3d.js` умеет ключи текстур с расширением: `.webp` рисуются сглаженно, остальное nearest, как раньше.
- **Рулетка:** 140 слотов, приз в слоте №95.
  - 70 тиков линейно на 90% пути, потом 30 тиков экспонента. Коэффициент k=3,75 подобран так, чтобы скорость на стыке фаз совпадала.
  - Затем 20 тиков показ приза, масштаб 2,4 → 10.
  - Звук `case_battle.ogg` из мода.
- **Кран-машина (06.2):** canvas-физика боксов, клешня, проскальзывание; выловленные боксы идут в инвентарь кейса, золотой даёт 3.
- **Текстуры фигурок:** `build_p06.py` обрезает каждую фото-текстуру до области, которую используют грани (uv пересчитываются), до 768 px; плоская графика и скины идут в PNG + nearest.
- **Фьюжн:** 9 фигурок одной редкости дают 1 случайную следующей. Кнопка «+9» насыпает фигурки как из креатива.
- **Ауры:** карта 21×21, зона — куб радиусом 6 (у Лабубу-анонимуса 3, у Будды Лабубу 8). Формулы лежат в `AU` в `app.js`.
- **Ключи localStorage:**
  - `zm:p06.col` — фигурки в инвентаре;
  - `zm:p06.seen` — коллекция навсегда;
  - `zm:p06.box` — боксы;
  - `zm:p06.stats` и `zm:p06.last` — статистика и последние дропы;
  - `zm:p06.adv` — ачивки;
  - `zm:p06.au` — расстановка на карте аур;
  - `zm:p06.claw` — статистика кран-машины;
  - `zm:p06.snd` — звук.
- Все звуки мода (только ogg) лежат в `mod-src/sounds/all/`, это база для следующих страниц.

## Общие звуки Minecraft (все страницы)

- `ZM.sfx(name, vol, rate)` в `shared/core.js`, файлы в `assets/sounds/mc/` (ванильные 1.19.2, ogg + mp3). Громкость: `SFX_VOLUME`.
- Звуки: `click`, `pop`, `orb`, `levelup`, `stone`, `hit`, `cloth`, `wood`, `page`, `equip`, `chest_open/close`, `toast_in/out`, `challenge`, `anvil`, `enchant`, `cave`.
- Любая кнопка, вкладка или переключатель сами щёлкают, если страница в тот же момент не проиграла свой звук. Атрибут `data-nosfx` отключает щелчок.
- Тост достижения играет `toast_in`, у испытаний — фанфары `challenge` (если страница не сыграла свой звук).
- Страницы со своей кнопкой звука подключают её через `ZM.sfx.bind(() => sndOn)`. Где своей кнопки нет (главная и №01), core рисует кнопку `.zm-sfx` (ключ `zm:sfx`).
- `ZM.sfx.ambient()` включает редкие тихие звуки пещеры (сейчас только на №01).
