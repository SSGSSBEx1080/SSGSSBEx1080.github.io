# №08 · Made in Heaven — механика (по коду мода)

Предмет `zitraksmode:made_in_heaven`: стак 1, зачаруемость 15, одноразовый.
Рецепт (`recipes/08_mih/made_in_heaven.json`): DDD / DCD / DDD, D = алмазный блок, C = часы.

## Активация (ПКМ)
- Если уже идёт активация на сервере: «Made in Heaven уже активирован! Подождите завершения...».
- Иначе предмет тратится, звук `made_in_heaven` (MASTER, громкость 100, 47 с), в чат: «Made in Heaven активирован...», погода ясная.
- Длительность 940 тиков, сброс на 720-м.

## Время (прибавка за тик, p = тик / 720)
| p | прибавка |
|---|---|
| < 0,7 | 20 + p^1,8 · 1000 |
| < 0,9 | 500 + sub · 1500 |
| < 0,97 | 2000 + sub² · 6000 |
| иначе | 8000 + sub³ · 10000 |

За 720 тиков набегает 703 955 тиков времени ≈ 29,3 суток. На 504-м тике стык формул: 544 → 500.
После сброса время держится на полудне до конца.

## Остальное
- Погода: при p > 0,8 каждые 30 тиков: 70% ясно, 30% дождь.
- Скорость: ×2,5 (p<0,3), ×3,5 (<0,6), ×5 (<0,85), ×8. FOV зафиксирован.
- Снаряды в радиусе 4,5 разворачиваются, скорость max(1,5; v), владелец — игрок.
- Частицы END_ROD и FIREWORK, лазеры с 500-го тика.
- Тряска камеры с 520-го тика 200 тиков: 0 → 0,2 → 0,6 → 1,4.
- Смерть отменяет: «Made in Heaven отменён: пользователь умер.», музыка стоп.

## Сброс (тик 720)
- В чат «⚡ СБРОС ВСЕЛЕННОЙ ⚡», случайный эффект на 2400 тиков, уровень II, из 12:
  регенерация, сопротивление, огнестойкость, подводное дыхание, ночное зрение, прилив здоровья,
  поглощение, насыщение, удача, плавное падение, герой деревни, грация дельфина.
  Сообщение: «✨ Получен эффект вселенной: X».
- Замена блоков: 100% в радиусе 8, дальше −5% за блок до 20. Только безопасные твёрдые блоки
  (не жидкости, бедрок, порталы, двери, кровати, цветы и т.п.). Без чар — случайный блок из реестра.

## Зачарования YOBYR_MAMOK / HOCHU_LABUBU
- Код: `YobyrMamokEnchantment.java`, `HochuLabubuEnchantment.java` (параметры одинаковые).
- Редкость RARE, категория MADE_IN_HEAVEN, максимум I, стоимость 12–35.
- Ставятся на книгу и на Made in Heaven; можно на книгах, есть в столе (discoverable), не сокровище.
- Совместимы друг с другом.
- Одно: радиус ÷4 (2 / 5). Оба: ÷2 (4 / 10), каждый блок 50/50 по таблицам.
- Ёбырь мамок: 80% HENTAI_BLOCK, иначе стержень Энда, чёрная/оранжевая шерсть, кварц, мак,
  красный тюльпан, розовый куст, кактус, лазурит.
- Хочу Лабубу: камень 35, золотой блок 20, LABUBU_BOX 20, мак/кактус/лазурит по 7, фигурка 4; плюс 10 фигурок сверху.
