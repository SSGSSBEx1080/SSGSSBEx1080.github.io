## Сиденье (DildoSeatEntity)
- Сиденье на высоте +0.5; блок проверяет его каждые 5 тиков и пересоздаёт.
- Свободное сиденье силой сажает ближайшего Mob в AABB inflate(0.9, 0.7, 0.9).
- `sittingTime` сбрасывается при смене седока.
- ≥100 тиков: «Моричёк» (только игрок): Сопротивление I + Удача V, обновление каждые 10 тиков, без частиц; «БЭД Варс»: ресурс каждые (1200–1600 тиков) / множитель: чем опаснее седок, тем быстрее. Enemy ×1.2, прочий Mob (житель) ×1.1, игрок и Animal ×1.0.
- ≥200 тиков: каждые 2 тика FALLING_LAVA + CRIMSON_SPORE (по 5), крик эндермена при `sittingTime % 60 == 0`. Ровно на 200 тиках игроку выдаётся триггер dildo_sat_long (ачивка «ГЕЙмерзкое кресло»).
- Пересадка как на сидушках из Minecraft 26.3: сидя, ПКМ по другому дилдо в пределах досягаемости (4.5 выживание / 5 креатив) → сразу на его сиденье, таймер с нуля. В ряд это прыжки до 4 блоков (в креативе до 5).
- Слезание: ближайшая свободная сторона на 1.5 блока (N/S/E/W), иначе сверху.

## Ванильные формулы, использованные на странице
- Улов: вес группы = max(floor(w + q·luck), 0). Рыба 85/−1, хлам 10/−2, сокровища 5/+2 → Удача V: 84.2 / 0 / 15.8 %.
- Стол: base = rand(8)+1+(shelves>>1)+rand(shelves+1); слоты max(base/3,1), base·2/3+1, max(base, shelves·2); уровень += 1+rand(3)+rand(3), ×(1±0.15). На 30 уровне «БЭД Варс» невозможен (модифицированный уровень > 25).
- Взрыв TNT: 1352 луча, f = 4·(0.7+rand·0.6), шаг 0.3, f −= (res+0.3)·0.3 в блоке и −0.225 каждый шаг; центр y+0.06125.
  Блок цел, если для всех лучей f0 ≤ 0.225·s + (res+0.3)·0.3 (s — шаг входа в клетку) → точная вероятность.
