# Java-исходники мода (для справки)

Исходники из мода. Сайт их не читает: цифры из них
перенесены руками в `data/p02_tnt.js`, и у каждой цифры там есть комментарий,
откуда она взялась.

| Файл | Что из него взято |
|---|---|
| `ModArmorMaterials.java` | материал `ZITRAKS` (ТНТ-броня): защита, прочность, зачаровываемость, твёрдость, ремонт ТНТ |
| `DemolitionistTradeRegistration.java` *(не сохранён, перенесён в data)* | все сделки жителя-подрывника по уровням |
| `DemolitionistTrades.java` *(не сохранён, перенесён в data)* | случайные сделки (кнопки, плиты, книги «Бомбардир», зачарованная броня, Супер-ТНТ 50%) |

Если в моде что-то поменялось, обнови файл здесь и цифры в `data/p02_tnt.js`.
